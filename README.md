# StockFit

투자성향과 종목의 적합도를 DART 공시 재무데이터로 분석하는 초보자용 웹 서비스 (v0.1, 시연용)

## 실행 방법 (Windows)

1. Node.js 18 이상이 필요해요. PowerShell에서 `node -v`로 확인하세요.
2. 이 폴더에서 `.env.example`을 복사해 `.env`로 이름을 바꾸고, `DART_API_KEY=` 뒤에 인증키를 붙여넣으세요.
3. 이 폴더에서 PowerShell을 열고 실행하세요.
   ```
   npm start
   ```
4. 브라우저에서 http://localhost:3000 을 여세요.

외부 라이브러리를 쓰지 않아서 `npm install`은 필요 없어요.

처음 실행하면 DART에서 상장사 고유번호 목록을 받아 `data/corp-codes.json`에 저장해요(하루 한 번 갱신).
터미널에 `상장사 N개 준비 완료`가 뜨면 상장사 전체를 이름이나 종목코드로 검색할 수 있어요.
`.env`에 키가 없으면 예시(가상) 데이터로 삼성전자, SK하이닉스, 현대자동차 3종목만 동작해요.

## 폴더 구조

| 파일 | 역할 |
|---|---|
| `server.js` | 서버. 화면 파일 제공 + `/api/analyze` 분석 API |
| `src/corpCodes.js` | DART 상장사 고유번호 목록 다운로드·저장·검색 |
| `src/stocks.js` | 키가 없을 때 쓰는 기본 3종목, 첫 화면 빠른 선택 종목, 검색 별명 |
| `src/industry.js` | 업종 코드(KSIC) → 업종 이름, 시장 구분 |
| `src/dart.js` | DART API 호출, 부채비율·영업이익률·ROE·매출성장률·배당 계산 |
| `src/scoring.js` | 설문 → 투자성향·가중치, 지표 → 기준 점수 → 적합도 |
| `src/explain.js` | 지표를 쉬운 문장으로 설명 (용어 뜻 + 이 회사 수치 해석 + 내 기준에서의 의미) |
| `src/sampleData.js` | 키가 없을 때 쓰는 예시 데이터 |
| `public/` | 화면 (HTML, CSS, JS) |

## 사용한 DART API

- `fnlttSinglAcnt` 단일회사 주요계정: 부채총계, 자본총계, 매출액, 영업이익, 당기순이익
- `alotMatter` 배당에 관한 사항: 현금배당수익률, 현금배당성향
- `corpCode` 고유번호 목록: 상장사 전체의 종목코드 ↔ 고유번호
- `company` 기업개황: 시장 구분, 업종 코드

## 적합도 계산 (v0)

1. 설문 3문항 → 위험 감수 점수(0~4) → 금융투자협회 5단계 성향 이름으로 간이 매핑
2. 설문 답변에 따라 4개 기준(안정성, 수익성, 성장성, 배당)의 비중을 정함
3. 지표마다 0점/100점 기준을 두고 직선으로 환산 (`src/scoring.js`의 `CRITERIA`)
4. 기준 점수 × 비중을 모두 더한 값 = 적합도. 데이터가 없는 기준은 빼고 비중을 다시 맞춤
